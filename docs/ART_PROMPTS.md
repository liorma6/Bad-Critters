# Production art prompts

Generated with Codex's built-in image generation tool. Each building was generated separately. The bakery established the style reference; the remaining four used it as an image reference. All five transparent outputs are integrated as WebP assets; the original PNGs remain in the generated_images folder. WebP encoding changes storage format only, preserving dimensions and alpha.

## bakery

Use case: stylized-concept. Production game asset, not a mockup: one isolated small Israeli neighborhood bakery building, genuinely transparent background, no ground tile, no sky, no people, no letters or words anywhere. Cohesive hand-painted 2D gouache game art, warm tactile animated-film set for an adult comic detective game, NOT preschool clip art, NOT sterile vector, NOT photorealistic. Camera: modest elevated three-quarter view, front facade dominant, narrow RIGHT side visible, roof top visible, no severe diamond isometry. Upper-left warm sunlight, deep teal contact shadows. Silhouette: charming asymmetrical single-story cream stucco bakery with an uneven terracotta tiled roof, small brick chimney, projecting faded coral-and-cream striped canvas awning, recessed teal wooden entry on front RIGHT, large warmly illuminated bread display window on front LEFT, tiny flour sacks and wicker bread trays, one crooked blank dark menu board, terracotta plant pot. Rough plaster edges, varied brush texture, chipped paint, subtle dimensional shading; confident readable forms that work at 240 pixels wide. Make the building fill 90 percent of the canvas, clean alpha edge, no baked floor shadow beyond a small contact shadow. Reserve a BLANK cream fascia for actual Hebrew text rendered later in code. Full silhouette fits with margin. Output a square transparent PNG sprite.
