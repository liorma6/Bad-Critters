# Creator audio and local personal dubbing


There are **133 authored creator lines**: 19 per principal resident across all cases, 7 guide lines, 7 for Amos and 5 for Rina. Each principal role needs 13 unique lines in the selected case (10 reusable plus 3 case-specific). The complete quick role has 5 lines: Amos in cases 1–2, Rina in case 3. Only the current case’s complete role can be personally cast. See `DIALOGUE_COVERAGE.md` for the full audit. The complete creator script includes solutions; the player sees full-role scripts only after explicit Hebrew spoiler acknowledgment. Quick-role scripts are safe. Build generates `RECORDING_SCRIPT.md`, printable `recording-script.html`, per-case `PERSONAL_LINES.md`, the line manifest and `assets/voices/recording-cases.json`.

Record one mono MP3 per ID and script version. For example: `goat.greet.v2.mp3`, `snake.courtyard.alibi.v1.mp3`, `boar.balcony.detail.v1.mp3`. Place files in `assets/voices/` and run `npm run build`, then `npm run deploy`. Suggested export is 44.1/48 kHz, 96–128 kbps, consistent perceived volume and a short clean lead-in. Filenames are case sensitive. Unversioned old recordings are deliberately ignored. MP3, M4A, Ogg, WebM and WAV are indexed, in that preference order; MP3 has broad playback compatibility. Do not rename extensions without converting the audio. Check actual browser playback after adding files.

For the personally cast character, every event uses the compatible accepted personal take. A missing or failed personal clip displays the exact Hebrew subtitle and offers repair after the active dialogue; it **never substitutes creator audio**. Every other character uses an installed creator recording or subtitles. Current case casting is explicitly confirmed and never carried to the next case. Missing creator clips do not cause requests. Media errors recover to text and stalled media loading is abandoned after 15 seconds. Audio loads only when needed. No precaching or service worker downloads the whole cast. Browser audio is unlocked by user actions. Speech is never synthesized.

`manifest.json` lists versioned filenames and an `installed` field; `null` means absent. The compact `available.json` contains only real, nonempty installed files. The case manifest lists every event and requirement. Keep text and manifests synchronized by rebuilding after changes. Change the script version when spoken text changes; recordings also require the exact text fingerprint and intended performance context.

Personal takes and automatic drafts stay in IndexedDB, with character and line identity, version, fingerprint, performance context, actual Blob/MIME, decoded duration, signal validity, review state and processing settings. Separate case/character set records store complete requirements and resume position. A stopped usable take autosaves as a draft; listening and approval mark it reviewed. The entire role is decoded and checked before personal casting. Storage failures retain a session draft with a warning. No upload, account or import/export is implemented. Data is scoped to the browser and origin. Settings offer recording/repair without changing the active case’s cast. See `COMPLETE_ROLE_DUBBING.md`.

The microphone is requested only on Record or Retry. AudioContext creation/resume runs synchronously in that click, before awaiting permission. The default records the microphone stream directly with browser processing disabled; an independent analyser measures the same input on a logarithmic scale. Browser noise suppression, echo cancellation and gain control are opt-in together, separately from optional 85 Hz high-pass / gentle 2:1 compression. Actual track settings are saved. The live input graph never connects to speakers. A complete recording must decode and contain measurable AC signal, then finish preview playback, before acceptance. The low signal floor allows quiet speech; digital silence and broken output are rejected. The recording screen includes an input selector after permission, local input preference, and expandable diagnostics without device identifiers. Track loss, active-recording tab hiding, navigation and dialog closure release capture; temporarily hiding a permission prompt does not cancel acquisition. See MICROPHONE_FIX.md for verified results and browser limits.

Voice playback alone feeds the analyser. Four RMS states drive registered textured jaw rigs in world sprites and portraits. The original lip region is split with a clip and its original lower-jaw texture is displaced by a small mesh; no flat skin patch or second mouth is placed over the artwork. Species-specific lips/beaks retain their painted texture. Speaking uses a stable idle body pose. Silence, buffering, pause, skipped dialogue and scene changes close/reset mouths. Music and effects bypass the voice analyser. Dialogue audio ends on the media `ended` event; reconstruction waits for the final speech to finish instead of cutting it at 20 seconds. Text-only lines retain a reading interval.

Each script entry contains stable ID, speaker, exact Hebrew, English direction, English trigger, filename and priority. Culprit `.detail` lines are admissions and play only during the corresponding reconstruction. Other follow-up testimony is available during questioning. Reusable watched, bell and sprinkler reactions also have subtitle fallback. UI instructions and reconstruction descriptions are written text; the guide speaks the seven listed onboarding/discovery lines.

## Voice contrast

- **ירחמיאל / goat:** old wiry male rasp, clipped territorial orders, sudden loud threats. The pavement is a serious matter to him.
- **נבו / pigeon:** young adult male, quick confidential whispers, thin bravado and nervous corrections. A genuine observation briefly makes him steady.
- **זלמן / snake:** intimate, gentle, unhurried adult male. Talk about furniture like old relationships. No cartoon hissing.
- **מרגלית / cat:** older severe female, precise diction and entitlement. Intimate with the plumbing, cold about money.
- **בני / boar:** heavy pressured salesman bass, breath between clauses, euphemisms delivered briskly. Stop joking when Rina's injury is mentioned.
- **צביקה / turtle:** deliberate adult male precision; a pause, then a sudden exact number. Clear, never sleepy or unintelligible.
- **Guide:** calm factual adult voice. Treat death, displacement and injury seriously.
- **עמוס / badger:** middle-aged auditor, dry and tired of excuses.
- **רינה / hedgehog:** adult tenant, ordinary and practical with a little doubt.

The release includes the approved recordings indexed by `assets/voices/published.json`. All dialogue remains playable and readable when a recording is missing. Raw studio sources and older takes are kept locally.
