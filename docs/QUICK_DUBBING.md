# Complete role dubbing — current design

The signature-only design has been replaced. See [COMPLETE_ROLE_DUBBING.md](COMPLETE_ROLE_DUBBING.md) for the current flow, casting rules, drafts, compatibility and repair.

[DIALOGUE_COVERAGE.md](DIALOGUE_COVERAGE.md) documents every role and branch, with before/after counts. [PERSONAL_LINES.md](PERSONAL_LINES.md) contains the generated Hebrew scripts and is explicitly marked for spoilers.

At each case, choose creator voices, its complete five-line supporting part, or one complete 13-line principal part. Incomplete roles stay drafts. The personal character never falls back to a creator voice. Every new case requires casting confirmation. The existing microphone fixes and diagnostics remain in place.
