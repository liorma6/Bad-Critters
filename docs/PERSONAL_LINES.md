# תסריטי דיבוב מלאים לפי תיק

אזהרה: התפקידים המלאים כוללים מידע מהחקירה ומהפתרון. רק התפקיד הקצר בכל תיק בטוח להקלטה מראש. הוראות המשחק אינן מציגות תסריט מלא לפני אישור אזהרה.

- **goat.arrival** (גרסה 1): פרחח, אכלתי יצורים כמוך לארוחת בוקר. עכשיו הרופא מרשה לי רק דייסה.

- **goat.fire.alibi** (גרסה 1): בחמש חמישים ושמונה מרגלית נכנסה לבד. בשש ושלוש יצאה. אני עמדתי מול הדלת.
  - משחק: לדבר אל השכן באופן טבעי. אפשר לקחת נשימה בין המשפטים.
- **goat.fire.detail** (גרסה 2): בני היה איתי על הספסל כל הזמן. אני זוכר טוב מאוד. הוא לא סתם את הפה.
  - משחק: האליבי חד וברור. רק אחריו לפרוק את העצבים.
