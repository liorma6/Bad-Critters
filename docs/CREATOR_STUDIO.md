# אולפן דיבוב היוצר

פותחים את `Start-Creator-Studio.cmd` בתיקיית המשחק, או מריצים `npm run studio` ופותחים http://127.0.0.1:4175/creator/ ב־Chrome. אין צורך להתחבר ל־Cloudflare. לחיצה על הקלטה היא הפעולה היחידה שפותחת את המיקרופון.

בוחרים דמות וחלק בתסריט, מקליטים, עוצרים, מאזינים ולוחצים ״שמור ועבור למשפט הבא״. ״עצירת האזנה״ מפסיק גם טייק חדש וגם טייק שמור באמצע. לאחר שהושמע חלק מהטייק החדש אפשר לשמור בלי לחכות לסיומו. אפשר לסנן לפי מצב, לדלג או להחליף טייק קיים. סגירת החלון משאירה את הקבצים בפרויקט; בפעם הבאה ממשיכים מהמשפט האחרון. טייק חדש שטרם נשמר מגובה בדפדפן כש־IndexedDB זמין. הוא אינו נחשב הקלטה רשמית עד שהשמירה בפרויקט מאושרת.

בחיתוך הקצוות מציינים כמה שניות להסיר מתחילת הטייק המלא ומסופו, ואז מחילים ומאזינים. הכפתור ״הסרת 0.2 שנ׳ מהסוף״ הוא קיצור דרך לקליק של עצירת ההקלטה. אין הסרה אוטומטית של דיבור. ״ביטול החיתוך״ מחזיר את הטייק המלא. ״חיתוך טייק שמור״ טוען את המקור השמור ומאפשר לשנות גם חיתוך שנשמר בעבר; הטייק הרשמי נשאר עד שמירת ההחלפה. כל שינוי דורש האזנה חדשה, שאפשר לעצור באמצע. העריכה נשמרת בגיבוי הדפדפן עד לשמירה בפרויקט. קצות החיתוך מקבלים מעבר עוצמה קצר של 5 אלפיות שנייה כדי למנוע קליק חדש בנקודת החיתוך.

באולפן, צמצום רעשי הדפדפן פועל בלי לבקש הגברה אוטומטית (AGC); הגדרות המכשיר שהתקבלו בפועל נרשמות עם הטייק. עיבוד הרעש תלוי בדפדפן ובמיקרופון, ואינו הבטחה להסרת הקלקות. החיתוך מאפשר להסיר קליק בקצה בלי סינון אגרסיבי של שאר הדיבור. בקרות הרעש וההגברה הן בקרות נפרדות ב[תקן לכידת המדיה](https://www.w3.org/TR/mediacapture-streams/#constrainable-properties).

הטקסט והזהות של כל משפט נטענים ממקור המשחק. שמירה של נוסח שהתיישן נדחית. הקלטות לגרסאות קודמות מסומנות ״דורשים הקלטה מחדש״ ואינן מנוגנות במשחק. הקריינות מופיעה בנפרד משמונה הדמויות.

## הקבצים

- `assets/voices/.creator-studio/library.json` — מניפסט האולפן, ההתקדמות ומיפוי הטייקים המאושרים. ההחלפה האטומית שלו היא אישור השמירה.
- `assets/voices/.creator-studio/takes/<take-id>/` — מקור לפני עיבוד האפליקציה והעתק של הגרסה הסופית. עיבוד דפדפן אופציונלי נרשם במטא־נתונים.
- `assets/voices/creator/` — קובצי הניגון בעלי שמות ייחודיים. טייקים קודמים נשמרים במחשב, אבל רק הטייק הפעיל לכל משפט מועתק להפצה.

כדאי לגבות את כל תיקיית `assets/voices`, כולל התיקייה המוסתרת. שינוי ידני של המניפסט או מחיקת קבצים אינו נחוץ. בזמן שהשירות פעיל, `assets/voices/available.json` בתצוגה המקומית נגזר מהמניפסט המאושר; הבנייה כותבת את המיפוי והנכסים המתאימים להפצה.

שיפור הקול משתמש במסנן ובדחיסה של מערכת ההקלטה הקיימת, פעם אחת לאחר ההקלטה. האזנת האולפן והמשחק משתמשים באותם בתים. מקור ללא שיפור נוסף נשמר בנפרד. שמירה שנכשלה אינה מחליפה את הטייק הקודם. ניסיון חוזר עם אותו טייק אינו משכפל שמירה שהושלמה.

## משחק ופרסום

״פתיחת המשחק המקומי״ באולפן פותחת http://127.0.0.1:4175/ ומאפשרת לבדוק את ההקלטות מיד. משחק שכבר פתוח מרענן את מיפוי הקולות לפני השמעה אחרי שתי שניות; כל החלפה מקבלת כתובת חדשה. תצוגת Wrangler ב־4174 מציגה את הבנייה האחרונה ומתעדכנת אחרי `npm run build`.

לאחר ההקלטות מריצים את תהליך הפרסום הקיים: `npm run deploy`. אם פגה ההתחברות ל־Cloudflare, מריצים קודם `npm run cf:login`. אין פריסה אוטומטית אחרי כל משפט. `npm run build` כולל רק טייקים פעילים המתאימים לנוסח הנוכחי; המקורות, ההיסטוריה, ממשק האולפן ושירות הכתיבה אינם מועתקים ל־dist.

השירות מאזין רק ל־127.0.0.1. פעולות כתיבה דורשות מקור זהה ואסימון של הפעלת השירות; שמות הקבצים נקבעים בשרת. אין נתיב כתיבה בגרסה הציבורית. כללי הדיבוב האישי והאיסור על השלמת תפקיד אישי בקול היוצר נשארים בתוקף.
